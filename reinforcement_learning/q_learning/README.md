# Q-learning

Reinforcement learning project using gymnasium (FrozenLake-v1) and numpy.

## Requirements

- Python 3.9
- numpy 1.25.2
- gymnasium 0.29.1
- pycodestyle 2.11.1

## Files

| File | Description |
|------|-------------|
| `0-load_env.py` | `load_frozen_lake(desc=None, map_name=None, is_slippery=False)` loads the pre-made FrozenLake environment |
