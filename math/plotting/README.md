# Plotting

This project contains Python scripts that use matplotlib to create various types of graphs and plots.

## Requirements

- Python 3.9
- numpy 1.25.2
- matplotlib 3.8.3

## Installation

```bash
pip install --user matplotlib==3.8.3
pip install --user Pillow==10.3.0
sudo apt-get install python3-tk
```
