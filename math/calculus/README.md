# Calculus 📐

This directory contains solutions for the **calculus** tasks in the machine learning project.

## 📘 Description

The project covers fundamental calculus concepts such as:

- Sigma (Σ) notation (summation)
- Pi (Π) notation (product)
- Series
- Derivatives
- Integrals
- Partial derivatives

## ✅ Task 0: Sigma is for Sum

File: `0-sigma_is_for_sum`

Sigma notation:

\[
\sum_{i=2}^{5} i
\]

Expanded form:

2 + 3 + 4 + 5

Correct answer (choice number):

3
