# Regularization

Techniques for reducing overfitting in neural networks: L2 regularization and Dropout.

## Tasks

| File | Description |
| --- | --- |
| `0-l2_reg_cost.py` | Calculates the cost of a neural network with L2 regularization |
| `1-l2_reg_gradient_descent.py` | Updates weights/biases using gradient descent with L2 regularization |
| `2-l2_reg_cost.py` | Calculates the cost of a Keras model with L2 regularization |
| `3-l2_reg_create_layer.py` | Creates a TensorFlow layer with L2 regularization |
| `4-dropout_forward_prop.py` | Conducts forward propagation using Dropout |
| `5-dropout_gradient_descent.py` | Updates weights using gradient descent with Dropout |
