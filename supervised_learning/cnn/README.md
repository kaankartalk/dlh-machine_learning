# Convolutional Neural Networks

This project implements the building blocks of Convolutional Neural
Networks (CNNs) from scratch using `numpy`, and also builds a
CNN using `tensorflow`/`keras`.

## Tasks

0. `0-conv_forward.py` - Convolutional Forward Prop
1. `1-pool_forward.py` - Pooling Forward Prop
2. `2-conv_backward.py` - Convolutional Back Prop
3. `3-pool_backward.py` - Pooling Back Prop
5. `5-lenet5.py` - LeNet-5 (Keras)

## Requirements

- Python 3
- numpy
- tensorflow
