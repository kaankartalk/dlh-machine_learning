# Keras

Building, optimizing, and preparing data for neural networks using the Keras library.

## Learning Objectives

* What is Keras?
* What is a model?
* How to instantiate a model (using the Sequential class and the functional API)
* How to build a layer
* How to add regularization to a layer
* How to add dropout to a layer
* How to optimize a model

## Requirements

* Ubuntu 20.04 LTS, Python 3.9, numpy 1.25.2, tensorflow 2.15
* All files interpreted/compiled on Ubuntu 20.04 LTS using `python3`
* Code follows `pycodestyle` (version 2.11.1)
* All modules, classes, and functions have documentation

## Tasks

| File | Description |
| --- | --- |
| `0-sequential.py` | Builds a neural network with the Keras `Sequential` class |
| `1-input.py` | Builds a neural network with the Keras functional API (`Input` class) |
| `2-optimize.py` | Sets up Adam optimization with categorical crossentropy loss and accuracy metrics |
| `3-one_hot.py` | Converts a label vector into a one-hot matrix |
