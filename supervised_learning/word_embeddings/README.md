# Word Embeddings

This directory contains tasks on natural language processing and word
embeddings, written in Python 3 with numpy and gensim.

## Requirements

* Python 3.9
* numpy 1.25.2
* gensim 4.3.2
* All files follow pycodestyle 2.11.0
* All files are executable and end with a new line
* All modules, classes and functions have documentation
* The `gensim` library is not allowed for the bag of words and TF-IDF tasks

## Files

| File | Description |
| --- | --- |
| `0-bag_of_words.py` | Function `bag_of_words(sentences, vocab=None)` that creates a bag of words embedding matrix |
| `1-tf_idf.py` | Function `tf_idf(sentences, vocab=None)` that creates a TF-IDF embedding |
| `2-word2vec.py` | Function `word2vec_model(sentences, ...)` that creates, builds and trains a gensim Word2Vec model |
