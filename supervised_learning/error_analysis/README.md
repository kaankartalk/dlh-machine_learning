# Error Analysis

Analyzing model performance using confusion matrices, and the bias/variance tradeoff.

## Learning Objectives

* What is the confusion matrix?
* What is type I error? type II?
* What is sensitivity? specificity? precision? recall?
* What is an F1 score?
* What is bias? variance?
* What is irreducible error?
* What is Bayes error?
* How can you approximate Bayes error?
* How to calculate bias and variance
* How to create a confusion matrix

## Requirements

* Ubuntu 20.04 LTS, Python 3.9, numpy 1.25.2
* All files interpreted/compiled on Ubuntu 20.04 LTS using `python3`
* Code follows `pycodestyle` (version 2.11.1)
* All modules and functions have documentation

## Tasks

| File | Description |
| --- | --- |
| `0-create_confusion.py` | Creates a confusion matrix |
| `1-sensitivity.py` | Calculates the sensitivity for each class in a confusion matrix |
| `2-precision.py` | Calculates the precision for each class in a confusion matrix |
| `3-specificity.py` | Calculates the specificity for each class in a confusion matrix |
| `4-f1_score.py` | Calculates the F1 score of a confusion matrix |
| `5-error_handling` | Approaches for handling different bias/variance scenarios |
| `6-compare_and_contrast` | Identifies the most important issue given training/validation confusion matrices |
