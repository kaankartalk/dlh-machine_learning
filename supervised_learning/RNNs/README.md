## Learning Objectives

At the end of this project, you are expected to be able to [explain to anyone](https://intranet-dlh.hbtn.io/rltoken/6t7vpchNer9b-NRkByo-LA), without the help of Google:

* What is a RNN?
* What is a LSTM?
* What is a GRU?
* What is a BRNN?
* What is the Exploding Gradient Problem? When does it occur?
* What is the Vanishing Gradient Problem? When does it occur?
* How do LSTM & GRU overcome the Vanishing Gradient Problem?
