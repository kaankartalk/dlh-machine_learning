# RNNs

Recurrent Neural Networks implemented from scratch with NumPy.

## Tasks

| File | Description |
|------|-------------|
| `0-rnn_cell.py` | `RNNCell` class: a cell of a simple RNN with a tanh hidden state and a softmax output |

## Requirements

- Python 3.9
- NumPy 1.25.2
- Style: pycodestyle 2.11.0
- All files start with `#!/usr/bin/env python3`, end with a new line, and are executable
- All modules, classes, and functions have docstrings
