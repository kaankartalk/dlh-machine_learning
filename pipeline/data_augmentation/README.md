# Data Augmentation

This project implements common image data augmentation techniques
using `tensorflow`, useful for expanding and diversifying training
datasets for computer vision models.

## Tasks

0. `0-flip.py` - Flip: flips an image horizontally
1. `1-crop.py` - Crop: performs a random crop of an image
2. `2-rotate.py` - Rotate: rotates an image 90 degrees counter-clockwise
3. `3-contrast.py` - Contrast: randomly adjusts the contrast of an image
4. `4-brightness.py` - Brightness: randomly changes the brightness of an image
5. `5-hue.py` - Hue: changes the hue of an image

## Requirements

- Python 3
- tensorflow
- tensorflow_datasets
- matplotlib
